"# AnthonyAzpur-LPII_T2_AZPUR_ANTHONY" 
Carpeta del Repositorio:
https://github.com/AnthonyAzpur/AnthonyAzpur-LPII_T2_AZPUR_ANTHONY.git

Sistema de Alquiler de Películas

Este es un proyecto hecho con Spring Boot y MySQL. Sirve para registrar clientes, alquilar películas, ver alquileres, y hacer devoluciones.

Tecnologías:
- Java 17  
- Spring Boot  
- Thymeleaf  
- MySQL  
- Bootstrap  

Pasos para usar:
1. Clonar el proyecto  
2. En MySQL, crear la base de datos con:  
   create database db2_azpur;  
3. Ir al archivo application.properties y poner tu usuario y clave  
4. Correr el proyecto desde tu IDE o con el comando:  
   mvn spring-boot:run  

Cómo funciona:
- Primero se registran las películas  
- Se puede registrar un alquiler, poniendo nombre, email, eligiendo película y cantidad  
- Se puede ver la lista de alquileres y los detalles  
- También se puede hacer la devolución  
- Se puede ver la lista de clientes, editar o borrar
